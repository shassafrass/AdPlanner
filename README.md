# DES 374 Media Launch Planner

A simplified, browser-based media planning and creative production tool
for **DES 374 Advertising**.

The planner is designed to teach the basic reasoning behind media
planning without requiring students to use a professional media-buying
platform. It connects **target audience → campaign objective → media
selection → fictional media budget → creative deliverables → exhibition
launch**.

## What the Planner Does

Students use the planner to:

-   Define a specific target audience and geographic market.
-   Separate audience research from unsupported assumptions.
-   Write a campaign objective.
-   Learn basic advertising and media-planning terminology in context.
-   Select an appropriate mix of media channels.
-   Allocate a fictional media budget across those channels.
-   Explain why each channel is appropriate for the audience and
    campaign.
-   Translate media selections into realistic, student-scale creative
    deliverables.
-   Identify when a media plan creates an unrealistic production
    workload.
-   Generate a consolidated Media + Exhibition Launch Plan.
-   Print or save the completed plan as a PDF.

## Campaign Endpoint

The **end-of-semester exhibition is Campaign Day 1**.

This project stops at campaign launch. Students are introduced to terms
such as **KPI (Key Performance Indicator)**, but they are **not required
to collect or simulate post-launch performance data**.

The purpose of the exercise is to demonstrate how an advertising
campaign moves from:

**Who are we talking to? → What are we trying to accomplish? → Where
should the campaign appear? → What will that media cost? → What creative
work must we make? → Are we ready to launch?**

## Media Budget vs. Creative Production

The planner deliberately separates two ideas:

**Media Budget**\
The fictional amount a client would spend to distribute advertising.

**Creative Production**\
The actual work students must design and produce before the exhibition.

Selecting a media channel therefore creates both a strategic decision
and a production consequence. For example, choosing Paid Social may
generate a launch-ready social presence, while choosing Outdoor/OOH may
generate a coordinated set of billboard executions.

The goal is not to simulate every asset a professional agency would
produce. The planner creates a **reasonable student-scale representation
of a campaign system**.

-   Radio

-   Transit
-   Print
-   Cinema
-   Retail Media
-   Experiential / Street

Students are encouraged to concentrate on approximately **3--4
well-justified channels** rather than selecting everything.

## How to Use

No installation, account, server, or subscription is required.

1.  Download `DES374_Media_Launch_Planner_v1.html`.
2.  Open the file in a modern web browser such as Chrome, Edge, Firefox,
    or Safari.
3.  Complete the planner from top to bottom.
4.  Select **GENERATE MEDIA + EXHIBITION PLAN**.
5.  Review the generated launch plan.
6.  Use **PRINT / SAVE PDF** to create a PDF if desired.

## Hosting on GitHub Pages

The planner can also be hosted as a simple static website.

For GitHub Pages, rename the HTML file to:

`index.html`

Place it in the root of the GitHub repository and enable **GitHub
Pages** in the repository settings.

Because the application currently runs entirely in the browser, it does
not require a database or backend server.

## Privacy

This version does not require student names, email addresses, accounts,
or institutional credentials. Information entered into the planner is
processed locally in the browser.

Students should still avoid entering private or sensitive information.

## Important Limitation

The planner is an **educational tool, not a professional media-buying
platform**.

Budgets, channel descriptions, terminology, and production
recommendations are intended to teach introductory media strategy and
campaign planning. They should not be interpreted as current vendor
quotes, guaranteed media performance, or professional buying
recommendations.
